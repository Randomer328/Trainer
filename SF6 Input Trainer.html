    Commands

    Keyboard: move with WASD or the arrow keys; Space also jumps. Opposite directions cancel to neutral (left+right, up/Space+down). Punches UIO (or ZXC) = LP MP HP. Kicks JKL (or VBN) = LK MK HK.

    Controller: d-pad or left stick. X Y RB = LP MP HP, A B RT = LK MK HK (standard layout, same as SF6’s default). Press any button once so the browser notices it.

    Combos: LP+LK = Throw, MP+MK = Drive Parry, HP+HK = Drive Impact. Shortcuts work: 323 for DP, 121 for reverse DP, and 360/720 take the four directions in any order. Timing is counted in frames (60 per second). In SF6 the whole motion has to be finished within roughly 11f for quarter circles and DPs, 12f for half circles and 32f for a 360; charge needs about 45f for most characters. Each result shows how many frames you took. Use Relaxed to double the windows while you learn. Use the facing button to practice from the left or right side.
